Fiche Synthétique
❌ Sans DevOps (La vie classique)
  • « Chez moi ça marche » : Le code fonctionne sur le PC du dev mais plante sur le serveur.
  • Tests oubliés : Pas le temps de tout retester manuellement avant chaque mise en ligne.
  • Déploiements manuels stressants : Commandes tapées à la main, risque d'erreur humaine élevé, coupures de service.
✅ Avec TaskFlow (La méthode DevOps)
  • Conteneurs Docker : L'application tourne dans une boîte identique partout (PC du dev, test, serveur).
  • Tests 100 % automatisés : Chaque changement de code est testé en quelques secondes.
  • Déploiement en 1 clic (ou zéro clic) : Un robot déploie sans couper l'application pour les utilisateurs.
⚙️ LE CŒUR DU PROJET : LE PIPELINE CI/CD AUTOMATISÉ (JENKINS) Durée totale : 35 secondes
1
Checkout
Récupère le code depuis Git automatiquement
2
Install
Installe les paquets nécessaires en parallèle
3
Tests
Exécute les 20 tests unitaires Jest
4
Build
Construit les images légères Docker
5
Deploy
Lance les nouveaux conteneurs sans coupure
6
Health
Vérifie que les services répondent bien en direct
🛡️ La Règle d'Or (Quality Gate) : Si un seul test échoue à l'étape 3, le robot bloque tout immédiatement. Les étapes 4, 5 et 6 sont annulées. Aucun bug n'arrive jamais en production !
💡 3 Concepts Clés Expliqués Simplement
1. Microservices (Node.js)

Au lieu d'avoir un seul bloc lourd, l'application est découpée en 2 petits programmes indépendants : User-Service (utilisateurs) et Task-Service (tâches). Si l'un redémarre, l'autre continue de fonctionner.

2. Docker & Compose

Une boîte magique qui emballe votre code avec ses dépendances exactes. Plus jamais de conflit de version entre Windows, Mac ou Linux : le conteneur tourne à l'identique partout.

3. Jenkins & CI/CD

Un majordome infatigable. Dès que vous sauvegardez votre code sur Git, il se charge de tout vérifier, tester et mettre en ligne à votre place, de jour comme de nuit.

Application de démonstration : TaskFlow (API REST Node.js/Express) Validation : 20/20 tests réussis • Déploiement sans interruption
